# 🧪 Kitchen Lab: Science Games for Kids

A playful chemistry website where kids learn by playing. Every game starts with a short lesson, so students can read, think, and then answer. Kids collect stars, climb ranks, and the site remembers their best scores.

**Play it live:** https://YOUR-USERNAME.github.io/kitchen-lab/

## Games

| Game | What you learn |
|---|---|
| 🍋 **Acid or Base?** | Sort 29 everyday items (lemon, soap, cola, bleach, tap water...) into acid, base, or neutral. You have 3 lives and play until they run out. |
| ⚛️ **Element Quiz** | Match 27 elements with their symbols, and learn why gold is "Au" and iron is "Fe". |
| 🃏 **Element Match** | A memory card game pairing element symbols with names. It gets bigger with every level. |
| 🎨 **Potion Mixer** | Mix red, yellow, blue and water drops to match a target color. 5 rounds, up to 15 stars. |

## Features
- A short lesson before every game, with a "Think:" tip to guide students
- Stars and ranks: Lab Helper → Junior Scientist → Chemist → Professor
- Best scores saved in the browser, so progress stays after closing the page
- Works on phones, tablets and computers
- Animated bubble background, and animations switch off for people who prefer reduced motion

## How to run
Open `index.html` in any web browser. Nothing to install and no internet needed.

## Publish it with GitHub Pages
1. Create a public repository named `kitchen-lab`.
2. Upload `index.html` and `README.md`.
3. Go to **Settings → Pages**, choose Branch `main` and folder `/ (root)`, then click **Save**.
4. After a minute or two, your site is live at `https://YOUR-USERNAME.github.io/kitchen-lab/`.

## Built with

## Safety note
Science is fun, but never taste or mix real chemicals at home without an adult. Some items in the game, like bleach, are dangerous.
